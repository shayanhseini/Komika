# بینایی پهپاد (Drone Vision) — راهنمای نصب و اتصال در یونیتی

این بسته همان «اپراتور پهپاد» نسخه‌ی کامپیوتر (مشک پهپاد) است، این بار داخل خودِ بازیِ
یونیتی (WebGL): همان حرکت بدن، همان منطق و همان قانون‌ها، بدون برنامه‌ی جدا و بدون
فشردن کلید روی ویندوز. هسته‌ی C# این بسته خط‌به‌خط از هسته‌ی پایتونِ نسخه‌ی سالم ترجمه
شده و روی ۲۷۸۴ فریم ضبط‌شده، فریم‌به‌فریم با آن یکی است.

## حرکت بدن

| بدن | نتیجه | جای کلید |
|---|---|---|
| هر دو دست مثل بال بالا، حدود نیم ثانیه | قفل بازیکن (کادر سبز) | — |
| بال‌ها کج: مچ چپ بالاتر از مچ راست | راست | D |
| بال‌ها کج: مچ راست بالاتر | چپ | A |
| هر دو مچ بالاتر از خط شانه | بالا | W |
| هر دو مچ پایین‌تر از خط شانه | پایین | S |
| دست‌ها آویزان | هیچ کلیدی | — |

چپ/راست و بالا/پایین هم‌زمان کار می‌کنند. کلید تا وقتی بدن در آن حالت است «نگه داشته»
می‌ماند (مثل پروفایل پهپاد). کلید فقط وقتی فعال است که بازیکن قفل باشد و بال‌ها باز.

## نصب (۵ قدم)

۱. پوشه‌ی `Packages/com.flightvision.dronevision` را در پوشه‌ی `Packages` پروژه کپی کنید.
۲. پوشه‌ی `Assets/WebGLTemplates/DroneVision` را در `Assets/WebGLTemplates` پروژه کپی کنید.
۳. در Project Settings → Player → WebGL → Resolution and Presentation، گزینه‌ی
   **WebGL Template** را روی **DroneVision** بگذارید.
۴. در صحنه‌ی اول یک GameObject خالی بسازید و کامپوننت **DroneVisionInput** را رویش بگذارید.
۵. بازی را به بدن وصل کنید (پایین)، WebGL بیلد بگیرید و روی **HTTPS** (یا localhost) اجرا کنید.

## اتصال بازی

ساده‌ترین راه (مثل نسخه‌ی کامپیوتر): در کدی که کلیدها را می‌خواند، `Input.` را به
`DroneVisionInput.` تغییر دهید:

```csharp
using DroneVision;
if (DroneVisionInput.GetKey(KeyCode.D)) TurnRight();
if (DroneVisionInput.GetKey(KeyCode.A)) TurnLeft();
if (DroneVisionInput.GetKey(KeyCode.W)) Climb();
if (DroneVisionInput.GetKey(KeyCode.S)) Dive();
```

کیبورد واقعی هم کار می‌کند. برای کنترل نرم‌تر: `DroneVisionInput.Instance.Roll` و `Pitch`
(بین ۱- تا ۱). برای شروع و توقف پرواز: رویداد `OnLockChanged` (سبز شدن کادر = شروع؛
گم شدن بازیکن بیش از ۱ ثانیه = توقف). جزئیات کامل و همه‌ی API در `README.md`.

## چیزی که بازیکن می‌بیند (آماده است، ساختن نمی‌خواهد)

- قبل از قفل: تصویر بزرگ دوربین (آینه‌ای) با کادر دور بازیکن (سفید ← طلایی ← سبز) و
  یک جمله‌ی راهنمای فارسی.
- بعد از قفل: تصویر کوچک گوشه با حاشیه‌ی سبز و **کادر اتصال** زیرش: نقطه‌ی سبز
  «متصل ✓» و چهار حرف کلید که موقع فشرده شدن روشن می‌شوند.
- هیچ‌کدام جلوی کلیک روی بازی را نمی‌گیرد.

## انتخاب دوربین

- مرورگر یک بار اجازه‌ی دوربین می‌خواهد و دوربین انتخاب‌شده را برای دفعه‌های بعد **به
  خاطر می‌سپارد**.
- در صفحه‌ی بازی **Ctrl + Shift + C** دوربین بعدی را انتخاب می‌کند (اسمش ۳ ثانیه نشان
  داده می‌شود) و همان را به خاطر می‌سپارد.
- با `?camera=2` در آخر آدرس صفحه، دوربین شماره‌ی ۲ از اول انتخاب می‌شود.

## آزمایش

- **داخل ادیتور (بدون دوربین):** Play بزنید؛ یک بازیکن مجازی بال‌ها را بالا می‌برد و قفل
  می‌شود و **کلیدهای جهت‌نما** بال‌هایش را کج یا بالا/پایین می‌برند، از همان هسته.
  نمونه‌ی `DroneVisionDebugHUD` مقدارها را نشان می‌دهد (F1).
- **با دوربین واقعی:** File → Build And Run برای WebGL (روی localhost دوربین مجاز است).
  روی سرور حتماً HTTPS.

## تنظیم حساسیت (در اینسپکتور)

| فیلد | پیش‌فرض | یعنی |
|---|---|---|
| rollEnter | ۰٫۵ | اختلاف ارتفاع دو مچ برای چپ و راست (بیشتر = سخت‌تر) |
| upMargin | ۰٫۲۵ | بالا: هر دو مچ این‌قدر بالاتر از خط شانه |
| downMargin | ۰٫۳ | پایین: هر دو مچ این‌قدر پایین‌تر از خط شانه |
| lockMs | ۴۵۰ | چند میلی‌ثانیه بال باز تا قفل |
| lockGraceMs | ۱۰۰۰ | بازیکنِ قفل‌شده چقدر می‌تواند پنهان شود و قفل نپرد |

عددها به اندازه‌ی عرض شانه‌ی خودِ بازیکن است، پس دور و نزدیک فرقی ندارد. مقدارهای پیش‌فرض
همان مقدارهای نسخه‌ی کامپیوتر است.

## چیزهایی که نباید تغییر کند

فایل‌های `Runtime/Core`، فایل `DroneVision.jslib` و پوشه‌های `dronevision` و `vendor`
داخل قالب WebGL. همه‌ی منطق آنجاست و با نسخه‌ی کامپیوتر یکی نگه داشته شده است.
